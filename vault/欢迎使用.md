# 黏菌任务记忆体(DeepSlime)

> 会话可弃,记忆永存

这个 vault 是 DeepSlime 的记忆浏览器层。**存储格式是纯 markdown,Obsidian 只是浏览器**——就算不用 Obsidian,数据也完整可读。

## 溯源面板(推荐先看这个)

本 vault 已内置 **DeepSlime 溯源面板**插件(自动启用):

1. 点击左侧边栏的 **网络(Network)** 图标,或执行命令 "打开 DeepSlime 溯源面板";
2. 面板显示**任务菌落**:全部任务按最近活动排序,每个任务显示状态、条目数、来源 agent;
3. 展开任务可看**接续简报**(state.md)和**逐条溯源**:每条记忆标注 agent、会话、时间、类型、置信度、摘要;
4. 面板顶部是**覆盖诚实区**:已接入哪些数据源、哪些未接入,缺口显式列出。

面板数据直接读 `slime-mold/tasks/*/log/entries.jsonl`(完整溯源,不受 MCP open 的 50 条上限限制)。

## 结构

- `slime-mold/tasks/` — 任务区域(每个任务一个文件夹:task.json / state.md / log/ / artifacts/)
- `slime-mold/skills/` — 程序记忆(skill 库,共享"方法"的载体)
- `slime-mold/sm-config.json` — 覆盖诚实区配置(已接入/未接入数据源)
- `slime-mold/ingest-state.json` — 摄入管线幂等清单(管线内部使用)

## 图谱视图

打开图谱视图(Graph view),你会看到任务菌落的可视化:活跃任务在生长,休眠任务缩小变暗。

## 数据来源与刷新

记忆由**摄入管线**从各 agent 会话写入(当前:Codex 98 会话 / DSH 7 会话 / Edge 浏览历史)。要增量摄入新数据,在项目目录运行:

```bash
node scripts/ingest.mjs \
  --vault "D:\Deepseek Harness\deepslime\vault" \
  --codex "C:\Users\Huawei\.codex\sessions" \
  --dsh "C:\Users\Huawei\.dsh\sessions\--D-Deepseek~0020Harness--" \
  --edge "C:\Users\Huawei\AppData\Local\Microsoft\Edge\User Data\Default\History" \
  --agent dsh --session "ingest-<日期>" --key "ingest-<日期>"
```

同一 `--key` 重复运行是幂等的(不产生重复条目);换新 `--key` 才追加新数据。面板刷新按钮(F5 或手动刷新)即可看到更新。

## 与 agent 的关系

任何 agent(DSH / Claude Code / Cursor)通过 MCP 读写这个 vault 里的任务记忆。会话可以随便开、随便关——记忆在这里,不丢。
